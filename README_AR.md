# نظام إدارة المحلات ونقاط البيع (الكاشير)

برنامج متكامل لإدارة المبيعات، المخزون، الفواتير، الديون، والمتجر الإلكتروني.

## خطوات التشغيل على جهاز الكمبيوتر بعد فك ضغط ملف الـ ZIP:

### المتطلبات الأساسية (مرة واحدة فقط):
1. تثبيت برنامج **Node.js** المجاني (نسخة LTS) من الموقع الرسمي:
   👉 https://nodejs.org

### طريقة التشغيل التلقائية (الأسهل في Windows):
1. فك ضغط ملف الـ ZIP.
2. انقر نقراً مزدوجاً على ملف: **`تشغيل_البرنامج.bat`**.
3. سيقوم البرنامج تلقائياً بتثبيت الملفات المطلوبة وفتح واجهة البرنامج في المتصفح على:
   `http://localhost:3000`

### طريقة التشغيل اليدوية عبر موجه الأوامر (CMD أو Terminal):
1. افتح مجلد المشروع في موجه الأوامر.
2. اكتب الأمر التالي واضغط Enter:
   ```bash
   npm install
   ```
3. بعد انتهاء التثبيت، شغّل البرنامج بالأمر:
   ```bash
   npm run dev
   ```
4. افتح الرابط التالي في متصفح Chrome أو Edge:
   `http://localhost:3000`

### تثبيته كبرنامج سطح مكتب دائم:
بعد فتح `http://localhost:3000` في متصفح Google Chrome، اضغط على زر **«تثبيت التطبيق»** من شريط العنوان لتثبيته كأيقونة مستقلة على سطح المكتب تعمل بدون أي أشرطة متصفح.
